# Zaalima IAM Server

Identity and Access Management (IAM) Server for the Zaalima Java Full Stack Internship Project 3.

## Technology Stack

- Java 17
- Spring Boot 3
- Spring Security
- Spring Data JPA
- PostgreSQL
- Bean Validation
- Lombok

## Planned IAM Capabilities

- OAuth 2.0
- OpenID Connect (OIDC)
- Single Sign-On (SSO)
- JWT with custom claims
- Role-Based Access Control
- Multi-Factor Authentication (MFA)
- TOTP and OTP
- Redis-based session/token support
- Token revocation
- Audit logging
- Rate limiting
- Docker deployment
- SSL/TLS

## Getting Started

Run on Windows:

```text
mvnw.cmd spring-boot:run
```

The application uses port `8080` initially.

PostgreSQL configuration will be added in the next implementation step.
