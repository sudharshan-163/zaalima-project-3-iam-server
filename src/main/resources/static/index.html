Overview

This frontend is intentionally limited to APIs and routes verified in the current backend. It does not assume any unimplemented dashboard, user list, or role-management screens.

Available

Authenticated profile access

Use /api/users/me with the current session to read and update the logged-in user's profile.

Available

User registration

Use POST /api/users/register with the verified JSON fields: username, email, and password.

Available

MFA flow

Use the verified MFA endpoints for setup, code verification, enabling, and disabling. No QR-code or mock MFA state is introduced.

Not available

User management dashboard

Not available with the current backend. No general user list endpoint or dashboard route is implemented.

Not available

Role administration UI

Only assignment/removal endpoints exist for role/authority operations; there is no dedicated roles listing page in the current API surface.
